# AWS Kinesis Local

aws-kinesis-local serves the Amazon Kinesis Data Streams API on your machine, for development and CI. It implements all 45 Kinesis operations, including enhanced fan-out, and ships as the npm package `@saidsef/aws-kinesis-local`, a Docker image and a Helm chart.

## Quick start

```bash
npx @saidsef/aws-kinesis-local --port 4567
```

Or with Docker:

```bash
docker run -d -p 4567:4567 docker.io/saidsef/aws-kinesis-local:latest
```

Then point any AWS client at it:

```bash
export AWS_ACCESS_KEY_ID=test AWS_SECRET_ACCESS_KEY=test AWS_REGION=eu-west-1
aws --endpoint-url http://localhost:4567 kinesis list-streams
```

The Docker image replaces kinesalite 3.3.3 and keeps its port, flags, environment variables, ARNs and error responses. [Upgrading from kinesalite](specs/upgrading.md) lists what changes.
