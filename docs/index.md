# Docker Kinesis Local

The image runs [kinesalite](https://github.com/mhart/kinesalite), a local emulator of the Amazon Kinesis Data Streams API, for development and CI. A Helm chart and Kustomize manifests deploy it to Kubernetes.

## Quick start

```bash
docker run -d -p 4567:4567 docker.io/saidsef/aws-kinesis-local:latest

export AWS_ACCESS_KEY_ID=test AWS_SECRET_ACCESS_KEY=test AWS_REGION=eu-west-1
aws --endpoint-url http://localhost:4567 kinesis list-streams
```

kinesalite implements 17 Kinesis operations and no enhanced fan-out. Read [Supported operations](supported-operations.md) before you point a Kinesis Client Library consumer at it.
